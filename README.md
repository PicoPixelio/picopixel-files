# PicoPixel LVGL Examples

Explore ready-made PicoPixel examples for building embedded user interfaces with **LVGL**. These projects demonstrate practical UI patterns you can study, customize, and export as LVGL C code for platforms such as **ESP32**, **Arduino**, and **M5Stack**.

Each example can be opened in PicoPixel to explore how its widgets, styles, assets, animations, fonts, and events are configured. Use them as learning resources or as starting points for your own embedded display projects.

## Examples

### [Animation Examples](https://picopixel.io/templates/animation-examples/)

Learn how to create LVGL animations with PicoPixel's visual animation editor. Explore individual property keyframes, timing, easing paths, playback modes, and event-triggered animations.

### [Speedometer Example](https://picopixel.io/templates/speedometer-example/)

Explore a complete embedded speedometer interface built with LVGL widgets. This example is a useful starting point for dashboards, gauges, vehicle displays, instrumentation panels, and ESP32 or M5Stack projects.

### [Fonts Example](https://picopixel.io/templates/fonts-example/)

See how fonts, sizes, symbols, and typography styles can be used in an LVGL project. Learn how PicoPixel's font management tools help prepare text and symbols for embedded displays without requiring a manual font-conversion workflow.

### [Events Example](https://picopixel.io/templates/events-example/)

Learn how to make an LVGL interface interactive with events and actions. Explore how widget input can trigger screen changes, animations, state changes, sprites, themes, and actions connected to your own application logic.

## Using the Examples

Open an example from one of the links above, then use it to:

- Learn how PicoPixel and LVGL features work together
- Inspect widget properties, styles, events, animations, and assets
- Customize the design for your own screen size and hardware
- Export LVGL C code for an ESP32, Arduino, M5Stack, or another LVGL-compatible target
- Build on an existing interface instead of starting from an empty canvas
